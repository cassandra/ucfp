"Own or rent?" is a switch that records the tenure fact: the Own case (value, purchase, mortgage balance) shows its fields; Rent and Neither carry no fields here (the monthly rent is a plan, set in Spending). Rendered outside the section's Next form, so its form is not nested. Without JavaScript every case renders, and the server reads only the fields the chosen tenure makes relevant. {% endcomment %}
