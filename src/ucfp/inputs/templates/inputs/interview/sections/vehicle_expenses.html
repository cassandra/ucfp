{% comment %} The Vehicle Expenses step (Plans flow), Profile-driven like the Debt plan. Left column: the household's *current* vehicles, each with a plan disposition (retain / sell / replace), then any *additional* net-new future vehicles; each is edited through its own async view outside the section's Next form, opening beneath its list. Right column: the shared per-car running costs. The disposition rows come from the Vehicles (Profile) section via `form.dispositions` (managed by `VehicleDispositionView`); the net-new list is `form.vehicles` (`VehicleFormView` / `VehicleDeleteView`); the running-costs table is `form.vehicle_costs_form` (`VehicleExpensesView`). Each running cost is entered once per car and applies to every car while owned. {% endcomment %}
