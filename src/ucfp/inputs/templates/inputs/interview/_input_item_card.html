{% comment %} One member of a collection, rendered as the input-item-card primitive (see docs/dev/frontend/interview-ui-guidelines.md). A bordered card: an optional `badge`, the `title` and an optional inline `headline`, an optional `flag` (a warning chip such as "Needs details"), right-aligned actions, and an optional muted `detail` line beneath. Actions are independent: Edit shows when `edit_url` is given (opening the editor in `editor_target`), Remove when `delete_url` is given (posting there and refreshing `list_target`). A `source_note` (verbatim, e.g. "From Profile" or "From Home") shows when the member cannot be removed here (no `delete_url`) -- it names where the member is owned, whether the card is otherwise read-only or still editable here (e.g. a vehicle whose plan is set here but whose facts live in Profile). A card with neither action reads as read-only. The member whose editor is open (`handle` == `active_handle`) shows the active state. Params: title, badge, headline, flag, detail, handle, active_handle, edit_url, delete_url, source_note, editor_target, list_target. {% endcomment %}
