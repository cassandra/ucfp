# Contributing to Landfall

Landfall is a small, independently built financial-planning tool, shared freely for
anyone to use. It is developed mainly by its maintainer, so the most valuable thing
you can contribute is simply **using it and saying what works and what doesn't**.

## Feedback, bugs, and ideas

This is the heart of it. Software built without real use tends to solve the wrong
problems, so your experience is genuinely useful.

- **Try it** — use the hosted version at
  [landfall.cassandrahq.com](https://landfall.cassandrahq.com), or run your own with
  the [Self-Hosting Guide](docs/SelfHosting.md).
- **Report a bug or request a feature** — open an issue on
  [GitHub](https://github.com/cassandra/ucfp/issues). Clear steps to reproduce, or a
  concrete description of the problem you're trying to solve, help the most.
- **Ask a question** — use GitHub Discussions.

For anything private — account, sign-in, or a security matter — see
[SECURITY.md](SECURITY.md) rather than filing a public issue.

## Contributing code

Code contributions are welcome. If you'd like to dig into the codebase, the
[Development Guide](docs/Development.md) covers the tech stack and how to set up a
local environment. The usual flow applies: fork the
repository, work on a feature branch, and open a pull request with a clear
description.

Whichever way you take part, please keep interactions kind and constructive, per our
[Code of Conduct](CODE_OF_CONDUCT.md).
